# Chat Search - User Guide

## How to Use Chat Search

### Opening Search

**Method 1: Click the Search Button**
1. Look for "Search Chats" in the sidebar menu
2. Click the button with the search icon 🔍
3. Search input appears at the top

**Method 2: Keyboard Shortcut**
1. Press `Ctrl+K` on Windows/Linux
2. Press `Cmd+K` on Mac
3. Works from anywhere in the app

### Searching Conversations

**Step 1: Type Your Query**
- Start typing in the search box
- Results filter automatically as you type
- No need to press Enter

**Step 2: View Results**
- Matching conversations appear below
- See how many results were found
- Matched text is highlighted in yellow

**Step 3: Select a Conversation**
- Click any result to open it
- Search closes automatically
- Continue chatting

### Search Examples

**Search by Topic:**
```
Search: "javascript"
Finds: All chats about JavaScript
```

**Search by Question:**
```
Search: "how to"
Finds: All "how to" questions you asked
```

**Search by Keyword:**
```
Search: "error"
Finds: Conversations mentioning errors
```

**Search by Name:**
```
Search: "react tutorial"
Finds: Chats with "React Tutorial" in title
```

### Closing Search

**Method 1: Click the X Button**
- Click the X icon in the search box
- Returns to normal view

**Method 2: Press Escape**
- Press `Esc` key on keyboard
- Quick way to exit search

**Method 3: Select a Chat**
- Click any conversation
- Opens chat and closes search

### Search Tips

✅ **Case doesn't matter** - "JavaScript" and "javascript" both work

✅ **Searches everywhere** - Looks in titles AND messages

✅ **Real-time results** - No need to wait or press Enter

✅ **Partial matches work** - "script" finds "JavaScript"

✅ **Multiple words** - "react hooks" finds conversations with both words

### What Gets Searched?

✅ Chat titles
✅ User messages
✅ AI responses
✅ All conversations (not just current one)

### Visual Indicators

**When searching:**
- 🔍 Search icon appears
- Input box at top of sidebar
- Result count shown
- Matching text highlighted

**When no results:**
- 🔍 Faded search icon
- "No conversations found" message
- "Clear search" button to reset

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` / `Cmd+K` | Open search |
| `Esc` | Close search |
| `Enter` | (in search box) - no action, just filters |

### Mobile Usage

**On Mobile Devices:**
1. Tap "Search Chats" in sidebar
2. Search input appears full-width
3. Type your query
4. Tap a result to open
5. Tap X to close search

**Mobile Tips:**
- Search works the same as desktop
- Touch-friendly buttons
- Swipe to scroll results
- Sidebar closes after selecting chat

### Common Use Cases

**Finding Old Conversations:**
```
1. Press Ctrl+K
2. Type a keyword you remember
3. Click the conversation
```

**Looking for Specific Information:**
```
1. Open search
2. Type the topic or keyword
3. Browse highlighted results
4. Select the relevant chat
```

**Organizing Your Chats:**
```
1. Search for a topic
2. See all related conversations
3. Rename or delete as needed
```

### Troubleshooting

**Q: Search not finding anything?**
- Check your spelling
- Try a shorter keyword
- Make sure you have conversations saved

**Q: Too many results?**
- Use more specific keywords
- Try exact phrases
- Combine multiple words

**Q: Keyboard shortcut not working?**
- Make sure you're in the app
- Try clicking in the window first
- Check if another app is using Ctrl+K

**Q: Highlights not showing?**
- Results are still filtered correctly
- Highlights appear in chat titles
- Try a different search term

### Best Practices

1. **Use specific keywords** - Better results with precise terms
2. **Try different words** - If one doesn't work, try synonyms
3. **Keep titles descriptive** - Makes searching easier later
4. **Use keyboard shortcuts** - Faster than clicking
5. **Clear search when done** - Returns to full chat list

### Privacy Note

🔒 All searches happen locally in your browser. No search data is sent to any server. Your conversations remain private.
